# 生图模型版本探针

## 先看元数据，再看画面

OpenAI 生成的 PNG 内嵌 C2PA 清单，`softwareAgent` 直接写着模型名和版本，这是唯一确定的判据：

```bash
strings -n 4 x.png | grep -oE 'gpt-image.version.[0-9.]+'
```

背景：ChatGPT Images 新版本会不定期对 ChatGPT 与 Codex 用户逐步放量。
Codex 内置 `image_gen` 工具不暴露 model 参数，换代由服务端决定，本地无法指定。
到账与否只能靠 C2PA 看。

## 画面级探针

各探针考察一个维度，用于在新版本放量后衡量实际提升：

| 编号 | 提示词要点 | 看什么 |
|---|---|---|
| A 信息图 | 竖版战报类图：标题、副标题、数张数据卡（含千分位数字、英文 ID、小数）、标注柱状图、页脚日期，并要求「不要多余文字」 | 文字逐字准确率；是否擅自加装饰性文字 |
| B 反射物理 | 雨夜橱窗：人物 + 动物 + 透明伞水珠，玻璃里同时映人和对面霓虹招牌，要求倒影文字镜像、地面倒影与光源一致 | 倒影是否镜像、主体是否都在倒影里、光色是否落到皮肤/衣物上 |
| D 手部交互 | 手部精细动作（握筷、持物）与手写汉字 | 手指数量与持物姿势、手写体汉字准确度 |
| E 局部改图 | 以某图为 `--ref`，只换背景，其余不动 | 主体像素级保持 |
| T 透明背景 | 徽章贴纸，要求真实 alpha 通道，不要棋盘格 | PNG colortype 是否为 6 且有 alpha<250 的像素 |
| F 多轮改图 | 以 B 为 `--ref` 连续两轮修改（改衣物颜色、加前景元素，均要求倒影同步） | 主体逐轮是否漂移；倒影是否同步 |

## 判读顺序

1. 先跑 `strings` 看 C2PA 版本。版本变了再跑画面探针，否则跑了也只是在测旧代际。
2. 画面级探针对相邻代际的区分度有限——真正能区分的是 C2PA 版本号和延迟。
3. 新版到账后优先复跑 A（多余文字是否收敛、真实数据是否更准）和 F（追加到第 4～5 轮看是否仍不漂移）。
4. 延迟：官方通常宣称新代际更快。同 prompt 重跑对比即可，注意链路本身含 Codex 会话开销。

## 重跑

```bash
python3 scripts/gptimage.py generate --out T.png --aspect square \
  --prompt '一枚游戏成就徽章贴纸……要求背景完全透明（真实 alpha 通道）'
strings -n 4 T.png | grep -oE 'gpt-image.version.[0-9.]+'
```
